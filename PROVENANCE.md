# Provenance

This repository reconstructs and professionalises the earlier 2026 project **“Kiberdrošības minimums ikvienam”**.

The archived source material contained:

- a 25-rule canonical master;
- a public README with the full 01–25 sequence;
- a deterministic-rendering specification for 9:16, 4:5, PDF, summary and video outputs;
- a previously generated Latvian 25-slide PDF.

The original five-part structure is preserved:

1. think before you act / domā pirms rīkojies;
2. protect accounts / sargā kontus;
3. protect devices and networks / sargā ierīces un tīklu;
4. recognise fraud / atpazīsti krāpšanu;
5. know what to do / zini, ko darīt.

The new repository introduces a global English baseline and treats Latvia-specific services and reporting paths as explicit localisation, not as universal guidance. Content and sources were revalidated on 2026-09-22.
