# Localisation policy

The English edition is the **global baseline**. It must not rely on Latvian institutions, reporting routes, phone numbers or nationally specific services.

Local editions may map a global control to a jurisdiction-specific implementation. For example:

- `C20` globally describes protective DNS or equivalent network filtering; the Latvian edition maps this to the CERT.LV/NIC.LV DNS firewall.
- `C25` globally says to use the relevant national cyber authority/law-enforcement route; the Latvian edition names CERT.LV and the relevant local response paths.

A local implementation note must never be presented as a universal requirement.
